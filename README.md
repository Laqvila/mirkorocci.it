# mirkorocci.it

Sito personale di **Mirko Rocci, Ph.D.** — pubblicato con GitHub Pages sul dominio
[mirkorocci.it](https://mirkorocci.it).

Sito statico in HTML/CSS/JS, quadrilingue (IT/EN/ES/FR).

## Aggiornare i contenuti
I contenuti che cambiano più spesso (news, rassegna stampa, pubblicazioni) si modificano
nel file [`js/contenuti.js`](js/contenuti.js). Vedi la [guida](GUIDA-MODIFICHE.md).
Ogni modifica pubblicata su `main` aggiorna il sito live in 1–2 minuti.
